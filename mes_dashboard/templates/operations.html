Understand data coverage

Connected means the dashboard can query MES. It does not mean every factory event has arrived.

Receipt time is when cloud MES stored an event. Production time is when the operation occurred. Backlog uploads can have recent receipt times and old production times.

Central Server queue and station heartbeats are not provided by the current cloud protocol. Check the local Central Server’s Cloud MES Sync tab for pending counts and retry errors.

Missing records can result from filters, incomplete uploads or missing identity links. Quality and unit metrics only describe the evidence available in MES.
